# Shyam Kumar — Portfolio

A recruiter-focused portfolio built with React, Vite and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Before deploying

Edit `src/main.jsx` and replace:

- `YOUR_EMAIL@example.com`
- `https://github.com/YOUR_USERNAME`
- `https://www.linkedin.com/in/YOUR_USERNAME/`

Replace the `#` links on each project with the actual GitHub/live-demo URLs.

If you have a PDF resume, put it at:

`public/resume.pdf`

## Deploy

This project can be deployed directly to Vercel or another static hosting service.
